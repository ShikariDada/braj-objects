# Design decisions

Every nontrivial motif needs a reason tied to the object, Braj, or the journey.
If no reason exists, the motif is removed.

## Decision: Object numbering (001–006)
Reason: products are designed as collectible editions; the number maps to a real SKU/order.
Where used: collection index, package grammar, PDP metadata.
Where NOT used: section labels, decorative numbering.

## Decision: Sandstone red (#9B4435 family)
Reason: place-specific reference to Mathura sculpture/stone vocabulary.
Where used: small product/brand accents, arch studies, one editorial beat per page max.
Where NOT used: gradient backgrounds, every CTA, glow effects.

## Decision: Deep Yamuna green (#183E3D)
Reason: ghat-light at dusk — dark reflective water against warm architecture.
Where used: the From Braj section, Vishram Ghat / Kusum Sarovar studies.
Where NOT used: generic page backgrounds, gradients.

## Decision: Square plates, 1px rules
Reason: the object is square; the archive is documentary. Radius and shadow would lie about the physical form.
Where used: product plates, facts rails, collection index.
Where NOT used: pill buttons, elevated cards.

## Decision: Newsreader + Anek Devanagari
Reason: proofed in /_lab/type against real copy — Latin, numerals, ₹ sign and Devanagari place names set together.
Where used: display headlines (Newsreader upright), body/metadata/Devanagari (Anek).
Where NOT used: italic luxury clichés, mono labels beyond genuine measurements.

## Decision: Poster-first 3D
Reason: the object must read instantly on any device; WebGL is enhancement.
Where used: hero, PDP viewer, construction lab.
Where NOT used: any content that only exists inside a canvas.
