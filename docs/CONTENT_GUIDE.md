# Content guide

Voice: concise, precise, place-aware, respectful, factual, confident.
Never: mystical filler, brochure language, luxury-adjective soup, startup copy.

- Product headline pattern: `Braj Object 003 / Vishram Ghat / Mathura`.
- Facts rail uses a `dl`; unknown values render TBD, never marketing language.
- CTAs: View object, See details, Add to bag, Complete the set, View collection, About the place.
- Banned: Elevate, passion, tradition-meets-innovation, essence, timeless elegance, seamlessly, journey, discover-magic.
- Devanagari: only reviewed place names (मथुरा, विश्राम घाट, द्वारकाधीश, गोवर्धन, कुसुम सरोवर, ब्रज). No decorative script.
